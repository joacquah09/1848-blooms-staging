# 1848 Blooms staging

Preview copy of the 1848 Blooms and Designs website. Nothing here affects the live site.

**Staging link:** https://joacquah09.github.io/1848-blooms-staging/

## Preview a change

1. Open the **Actions** tab of this repo and pick **Preview on staging**.
2. Click **Run workflow**, type the pull request number from [joacquah09/1848-blooms-site](https://github.com/joacquah09/1848-blooms-site/pulls) (for example `4`), and click the green **Run workflow** button.
3. Wait about a minute for the green tick, then open the staging link. A small red "Staging preview" tag in the corner shows what you are looking at.

Type `main` instead of a number to put the current live version back on staging.
